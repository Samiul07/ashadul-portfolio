## Working speed

Default to fast iteration mode.

- Make the smallest scoped change first.
- Show the first usable result as quickly as possible.
- Do not browse unless explicitly requested.
- Do not run the complete production build during early UI iteration.
- Use focused lint/type checks for the edited files.
- Run exhaustive responsive, browser, accessibility, and production checks only when the user says to finalize.
- Time-box the first pass to approximately 3 minutes.
